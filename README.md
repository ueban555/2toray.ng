# 🚀 Космический Кликер

Добро пожаловать в захватывающую космическую кликер-игру! Исследуйте галактику, собирайте энергию и покоряйте вселенную!

## 🎮 Как играть

1. **Кликайте по планете** 🌍 - каждый клик дает вам энергию
2. **Покупайте улучшения** - используйте накопленную энергию для покупки улучшений
3. **Автоматизируйте** - покупайте генераторы для автоматического получения энергии
4. **Прогрессируйте** - покупайте все более мощные улучшения

## 🛸 Улучшения

- **👆 Космический Палец** - увеличивает силу ваших кликов
- **⚡ Энерго-генератор** - автоматически генерирует энергию
- **🏭 Космо-завод** - производит больше энергии в секунду
- **⛏️ Астероидная Шахта** - добывает энергию из астероидов
- **🛸 Звездолёт** - самый мощный генератор энергии

## ✨ Особенности

- 🎨 **Красивый дизайн** с космической тематикой
- 💫 **Анимированный фон** со звездами
- 📱 **Адаптивный интерфейс** для мобильных устройств
- 💾 **Автосохранение** прогресса в браузере
- 🕐 **Оффлайн прогресс** - энергия накапливается даже когда вы не играете
- ⚡ **Плавные анимации** и визуальные эффекты
- 🎯 **Система балансировки** с экспоненциальным ростом цен

## 🚀 Запуск игры

1. Просто откройте файл `index.html` в любом современном браузере
2. Начните кликать и наслаждайтесь игрой!

## 🛠️ Технологии

- **HTML5** - структура игры
- **CSS3** - стили и анимации
- **JavaScript ES6** - игровая логика
- **LocalStorage** - сохранение прогресса

## 🎯 Цель игры

Ваша цель - стать владыкой галактики! Накапливайте как можно больше энергии, покупайте улучшения и создавайте свою космическую империю.

Удачи в покорении космоса! 🌌
