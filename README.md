# 2toray.ng

Веб-сайт для исследования теорий и обсуждений.

## Описание проекта

2toray.ng - это платформа для:
- Изучения различных теорий
- Обсуждения интересных тем
- Просмотра галереи материалов
- Получения ответов на часто задаваемые вопросы

## Структура проекта

- `index.html` - Главная страница
- `styles.css` - Стили оформления
- Дополнительные страницы (в разработке):
  - `teorii.html` - Страница теорий
  - `obsuzhdeniya.html` - Страница обсуждений
  - `galereya.html` - Галерея
  - `faq.html` - Часто задаваемые вопросы
  - `kontakty.html` - Контактная информация

## Технологии

- HTML5
- CSS3
- Responsive дизайн

## Запуск

Откройте файл `index.html` в любом современном веб-браузере.
